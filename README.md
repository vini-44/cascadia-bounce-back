# cascadia bounce back

a 2d game about restoring water and power to a city, made for hack club haven seattle.

## how to play

- place wells for $100 to give nearby homes water and turn the surrounding grass green.
- place generators for $250 to give nearby homes power.

## controls

| input | action |
| --- | --- |
| wasd | move |
| q | zoom in |
| e | zoom out |
| left click | confirm placement |
| esc | cancel placement |

use the well and generator buttons to preview where to build. adjust the master volume from the main menu settings.
